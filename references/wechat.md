# 微信采集攻略

## 适用场景

- 群聊消息（群内他人的发言与时间）
- 单聊消息（自己的聊天记录备份）

## 导航要点

- 目标通常是「进入某个群聊/单聊页面」。导航任务直接给群名：
  `--app wechat --target "群名"`。
- StepAgent 的默认策略：先在聊天列表直接找，找不到用搜索框（Type 动作
  依赖 ADB Keyboard，请先在手机上安装 [AdbKeyboard](https://github.com/nicnocquee/AdbKeyboard)）。
- 如果群不在列表顶部，提示词会让 agent 搜索；搜索结果选完全匹配项。

## 滚动与停止

- 手指上滑 = 查看更早的历史消息，每屏保留 60% 重叠。
- 停止条件：连续 2 屏无新条目（`--max-screens` 之前生效），即认为到达
  已读边界。首次全量采集可调大 `--max-screens`（如 30~50）。

## 提取字段约定

| 字段 | 说明 |
|------|------|
| `sender` | 白色气泡取昵称；机主自己（绿色气泡）固定为「我」 |
| `text` | 文字内容；图片 `[图片]`、语音 `[语音 X秒]`、链接 `[链接: 标题]` |
| `time_hint` | 截图相对时间已由提示词换算为绝对时间 |
| `type` | text / image / voice / video / link / sticker / system |

## 注意事项

1. **不要在采集期间使用手机**：agent 与人共用一块屏幕会互相干扰。
2. 群名中若含 emoji，搜索输入可能失败——改用群名主体文字。
3. 微信首页可能有未读红点、弹窗广告，导航提示词已包含 Back 处理；
   若卡住可手动清理后用 `--no-navigate` 续采。
4. 聊天记录属于个人信息：采集自己参与的会话、控制留存范围，遵守
   《个人信息保护法》与微信用户协议。
