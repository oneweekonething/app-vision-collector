# 小红书采集攻略

## 适用场景

- 搜索结果页的笔记卡片（标题、作者、点赞数）
- 笔记详情页正文与评论

## 导航要点

- 搜索型采集：`--app xiaohongshu --target "关键词"`，
  agent 会打开 App → 点击搜索框 → 输入关键词 → 停留在结果页。
- 结果页信息流每滑一屏约 2~4 张卡片，`--max-screens 10` 约可覆盖 20~40 篇。
- 详情页采集建议 `--no-scroll`（一屏）或先由 agent 进入某篇笔记再翻评论。

## 提取字段约定

| 字段 | 说明 |
|------|------|
| `type` | 搜索结果/信息流卡片 = note；评论 = comment |
| `title` | 笔记标题（卡片上的加粗文字） |
| `sender` | 作者昵称 |
| `extra` | 放点赞数、收藏数等可见数据，如 `{"likes": "1.2万"}` |
| `time_hint` | 详情页通常显示相对时间，已自动换算 |

## 注意事项

1. 小红书对自动化滑动较敏感：本项目的随机抖动可降低风险，但请控制
   单次采集屏数与频率，不要长时间连续运行。
2. 未登录状态下很多内容不可见，请在已登录账号上采集。
3. 只采集公开可见内容并遵守其用户协议；笔记数据用于个人整理/研究，
   不得批量转售或二次分发生者的内容。
