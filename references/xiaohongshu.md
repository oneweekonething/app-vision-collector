# 小红书采集攻略

适用于搜索结果卡片、笔记详情与可见评论。使用 [调用者工作流](caller-workflow.md)。

## 导航与翻页

start 使用 `--app xiaohongshu --target "关键词"`，task 写明完整目标和字段。
调用者 observe 看图，打开搜索框、确认焦点、Type 关键词，然后看图确认搜索结果。
选择笔记详情时从最新截图取坐标；评论区域如入口被护栏拒绝，不绕过护栏。

信息流手指上滑：Swipe `start:[500,700],end:[500,300]`。先 record 当前屏再滚动，
等待加载、observe 看图、capture 留证，重新读取证据图并提取。单屏任务 record 后收尾。

## 字段

| 字段 | 说明 |
|------|------|
| type | 卡片/笔记 = note，评论 = comment |
| title | 可见笔记标题 |
| sender | 可见作者昵称 |
| extra | 可见点赞数、收藏数等，例如 `{"likes":"1.2万"}` |
| time_hint | 可见发布时间；明确相对时间可按提示词换算，否则 null |

使用 global 去重（auto 默认），连续两屏零新增且画面不再位移时停止。
控制用户授权范围与频率，遵守平台规则，不执行点赞、收藏、关注或发表评论。
